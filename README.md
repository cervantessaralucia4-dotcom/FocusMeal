# 🍽️ FocusMeal

Una plataforma web inteligente enfocada en la gestión de alimentación saludable, diseñada para ayudar a los usuarios a mejorar sus hábitos alimenticios según sus objetivos físicos y nutricionales.

---

## 🚀 Descripción del Proyecto

**FocusMeal** es una aplicación web moderna orientada al control y planificación de comidas, permitiendo a los usuarios:

* Gestionar alimentos y comidas
* Organizar planes alimenticios
* Monitorear objetivos físicos
* Llevar seguimiento nutricional
* Visualizar estadísticas de consumo
* Administrar usuarios y productos desde un panel administrativo

La plataforma fue diseñada con una experiencia visual moderna, intuitiva y responsive, ofreciendo una interfaz limpia y profesional tanto para usuarios como administradores.

---

## 🎯 Objetivos del Proyecto

El objetivo principal de FocusMeal es ayudar a las personas a:

* Mejorar sus hábitos alimenticios
* Llevar control de su alimentación diaria
* Alcanzar metas como:

  * Subir de peso
  * Bajar de peso
  * Mantener una alimentación balanceada
* Facilitar el acceso a información nutricional organizada
* Brindar una experiencia digital cómoda y moderna
